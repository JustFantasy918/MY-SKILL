# 四柱预测12步流程

> 蒸馏自邵伟华《四柱预测学》第13章

## 免责声明
命理学属于传统文化研究范畴，以下流程仅供参考，不构成科学预测。

## 12步流程

### 第1步：确认生辰准确性
- 确认出生年月日时（公历/农历）
- 确认出生地点（经度影响真太阳时）
- 确认性别（影响大运顺逆）
- 特别注意子时（23-1点）的日期归属问题

### 第2步：排四柱及十神、神煞
- 排年柱、月柱、日柱、时柱
- 计算各柱十神（天干十神 + 地支藏干十神）
- 计算纳音、胎元、命宫、身宫
- 计算空亡、旬空

### 第3步：看日干生于旺月还是衰月
- 确定月支五行
- 判断日干在月支的十二长生状态
- 初判得令/失令

### 第4步：看日干得其余地支之气否
- 检查年支、日支、时支中是否有日干根气
- 检查地支藏干中是否有日干同类
- 判断得地/失地

### 第5步：看日干得印星生扶否
- 检查四柱天干和地支藏干中是否有印星
- 印星是否有根有力
- 判断得生/失生

### 第6步：看日干得其余天干帮身否
- 检查四柱天干中是否有比劫
- 比劫是否有根
- 判断得助/失助

### 第7步：统筹衡量身旺还是身弱
- 综合得令、得地、得生、得助四要素
- 给出旺衰判断结果和置信度
- 标注特殊格局（如有）

### 第8步：找出用神、忌神
- 根据旺衰结果应用扶抑法
- 检查是否需要调候
- 检查是否需要通关
- 确定用神、喜神、忌神、仇神

### 第9步：定富贵贫贱吉凶寿夭局
- 看官星（事业/地位）
- 看财星（财富）
- 看印星（学业/名望）
- 看食伤（才华/子女）
- 综合判断命局层次

### 第10步：定运程兴衰吉凶
- 排大运8步
- 判断每步大运与用神的关系
- 标注大运吉凶

### 第11步：定最吉最凶之年及所应之事
- 在当前大运中找流年吉凶
- 标注最吉和最凶的年份
- 根据十神属性推断可能的人事

### 第12步：兼看心性、相貌、人品、财官、事业、疾病、婚姻、儿女

**心性**：看日干五行和十神心性
- 从四柱生化有情与否 → 有情有义还是无情无义
- 从四柱寒暖湿燥 → 热心合群还是冷峻孤僻
- 从四柱刚柔中正 → 君子还是小人

**事业**：看官星和印星旺衰
**财运**：看财星旺衰，身旺能胜财否
**婚姻**：看日支和财/官星
**健康**：看五行太过或不及
**儿女**：看食伤和时柱

## 断事要点

- 吉凶程度：大运定趋势，流年定具体
- 应事方向：十神所主之事 + 六亲所在之宫
- 应事时间：五行受冲合或受生克之月
- 命局组合最好时期好到什么程度 → 根据十神应什么好事
- 命局组合最坏时期坏到什么程度 → 根据十神应什么坏事
