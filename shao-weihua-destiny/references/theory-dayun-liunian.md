# 大运流年理论

> 蒸馏自邵伟华《四柱预测学》第8章

## 排大运

### 顺逆规则

| 年干阴阳 | 性别 | 大运排法 |
|---------|------|---------|
| 阳年（甲丙戊庚壬） | 男 | 顺排 |
| 阳年（甲丙戊庚壬） | 女 | 逆排 |
| 阴年（乙丁己辛癸） | 男 | 逆排 |
| 阴年（乙丁己辛癸） | 女 | 顺排 |

### 起运数计算

- **三天折一岁**（3天=1岁，1天=4个月，1时辰=10天）
- 顺排：从出生日数到**下一个节气**
- 逆排：从出生日数到**上一个节气**
- 得到的天数除以3即为起运岁数
- 余数：多1天=4个月，多2天=8个月

### 大运排列

- 从**月柱**开始
- 顺排：干支各进一位（如月柱庚寅，第一步辛卯、第二步壬辰...）
- 逆排：干支各退一位（如月柱庚寅，第一步己丑、第二步戊子...）
- 每步大运管**10年**
- 一般排**8步大运**（80年）

## 流年

- 流年即每一年的干支（以**立春**为年界）
- 每年一柱，60年一循环
- 流年天干与地支的关系如大运干支的君臣关系

## 岁运吉凶总论

### 大运吉凶判断

- 大运十神为用神所喜 → 好运
- 大运十神为用神所忌 → 坏运
- 大运五行与用神一致 → 吉
- 大运五行与忌神一致 → 凶
- 大运干支相生为佳、相克为差

### 流年吉凶判断

- 流年五行与用神一致 → 吉
- 流年五行与用神相克 → 凶
- 流年与大运的关系也影响吉凶

### 岁运吉凶矩阵

| 大运 | 流年 | 综合吉凶 |
|------|------|---------|
| 吉 | 吉 | 大吉 |
| 吉 | 平 | 吉 |
| 吉 | 凶 | 多吉少凶 |
| 平 | 吉 | 小吉 |
| 平 | 平 | 平运 |
| 平 | 凶 | 小凶 |
| 凶 | 吉 | 多凶少吉 |
| 凶 | 平 | 凶 |
| 凶 | 凶 | 大凶 |

### 大运天干的作用

1. 参与四柱天干透出十神（含地支藏干十神）的综合平衡
2. 是吉或凶的**划分阶段**
3. 作为六亲的生克对象，判断六亲吉凶

### 大运地支的作用

1. 参与四柱地支刑冲克合会害的综合平衡
2. 参与四柱干支、大运天干的综合平衡，扶抑用神
3. 从刑合冲会害中判断六亲吉凶

## 岁运与四柱的关系

- 大运冲克四柱 → 不利
- 流年冲克四柱 → 变动
- 大运流年与四柱合 → 有助力
- 四柱命局冲克大运流年 → 其凶尤甚
- 凶事应在流年忌神旺相冲克之**月**

## 重要原则

- 命好不如运好，运好不如流年好
- 命、运、流年三者密不可分
- 没有好命，大运于事无补
- 没有好运，命再好也背时
- 没有好的流年，大运虽好也难以兑现

## 冲合规则

- 冲去或合住忌神 → 吉
- 冲去或合住用神 → 凶
- 有制之时，十神作用有失但不尽失
- 岁运现则旺而生克，应在旺年之月
