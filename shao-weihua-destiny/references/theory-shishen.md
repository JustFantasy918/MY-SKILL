# 十神理论

> 蒸馏自邵伟华《四柱预测学》第4、6章

## 十神定义（以日干为我）

日干代表"我"，其他天干与日干的关系分为五类，每类分阴阳（正/偏），共十神：

| 关系 | 同性（偏） | 异性（正） | 含义 |
|------|-----------|-----------|------|
| 生我 | 偏印（枭神） | 正印 | 父母、庇护、学问 |
| 我生 | 食神 | 伤官 | 儿女、才华、表达 |
| 克我 | 七杀（偏官） | 正官 | 事业、管束、地位 |
| 我克 | 偏财 | 正财 | 财富、欲望、妻（男命） |
| 同我 | 比肩 | 劫财 | 兄弟、竞争、合作 |

**阴阳判断**：阳干见阳干=同性=偏；阳干见阴干=异性=正。阴干同理。

## 十神生克关系

**相生链**：官杀 → 印星 → 比劫 → 食伤 → 财星 → 官杀
**相克链**：官杀 → 比劫 → 财星 → 印星 → 食伤 → 官杀

## 十神心性（性格映射）

### 正官
- **心性**：正直负责、端庄严肃、循规蹈矩
- **负面**：刻板、墨守成规、意志不坚
- **主事**：官位、职位、考试、名誉。女命代表夫缘

### 七杀（偏官）
- **心性**：豪爽侠义、积极进取、威严机敏
- **负面**：偏激、叛逆、霸道
- **主事**：军警武职、司法。女命代表夫缘

### 正印
- **心性**：聪颖仁慈、淡泊名利、逆来顺受
- **负面**：庸碌、缺乏进取、迟钝
- **主事**：学业、学术、事业、名誉。代表母缘

### 偏印（枭神）
- **心性**：精明干练、反应机警、多才多艺
- **负面**：孤独、缺乏人情、自私冷漠
- **主事**：艺术、医业、律师、宗教、技艺

### 比肩
- **心性**：稳健刚毅、冒险勇敢、积极进取
- **负面**：孤僻、缺乏合群
- **主事**：手足、朋友、同事、合伙事业

### 劫财
- **心性**：热诚坦直、坚韧志旺、奋斗不屈
- **负面**：盲目、缺乏理智、蛮横冲动
- **主事**：损财、夺财、争权夺利

### 食神
- **心性**：温文随和、待人宽厚、善良体贴
- **负面**：虚伪、缺乏是非、迂腐
- **主事**：福寿、食禄。女命代表女儿缘

### 伤官
- **心性**：聪明活跃、才华横溢、逞强好胜
- **负面**：任性、缺乏约束、桀骜不驯
- **主事**：退职、失权、落选。女命代表子缘

### 正财
- **心性**：勤劳节俭、踏实保守、任劳任怨
- **负面**：苟且、缺乏进取、懦弱
- **主事**：俸禄、产业、财运、妻缘

### 偏财
- **心性**：慷慨重情、聪敏机灵、乐观开朗
- **负面**：虚浮、缺乏节制、浮华风流
- **主事**：横财、暴发、父缘

## "破则立"关系

邵伟华理论核心：当某十神被克破时，被它所克的十神就得以显现心性。

- 印克伤 → 伤不克官 → 正官心性现
- 枭夺食 → 食不制杀 → 七杀心性现
- 劫争财 → 财不损印 → 正印心性现
- 比夺财 → 财不克枭 → 枭神心性现
- 伤克官 → 官不制劫 → 劫财心性现
- 食制杀 → 杀不制比 → 比肩心性现

另有"不破也立"：某十神旺而不受损，其心性同样显露。

## 十神旺衰判断

- 得令（月支）旺、失令衰
- 多则旺、少则衰
- 有根（地支有同类）则有力、无根则无力
