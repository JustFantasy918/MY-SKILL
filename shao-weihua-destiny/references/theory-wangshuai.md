# 日干旺衰判断理论

> 蒸馏自邵伟华《四柱预测学》第5章

## 旺衰判断四要素

日干旺衰是四柱预测的核心基础，一生吉凶祸福的推断由此着手。

### 1. 得令（月令，权重最大约40%）

日干旺于月支为"得令"：
- 日干在月支处**长生、沐浴、冠带、临官、帝旺** → 得令（旺）
- 日干在月支处**衰、病、死、墓、绝** → 失令（衰）
- 月支为日干的**禄**或**刃** → 特别旺

月令是衡量旺衰的"纲"，权重最大。

### 2. 得地（地支根气，约25%）

日干在其余地支（年支、日支、时支）有根：
- 得**长生**（须阳干）、**禄刃**、**墓库** → 有根
- 地支藏干中有日干同类五行 → 有气
- 根气多寡影响旺衰程度

### 3. 得生（印星生扶，约20%）

四柱中有正印或偏印生扶日干：
- 印星在月干或时干紧贴日干 → 力量大
- 印星得令则生扶力强
- 印星有根则有力

### 4. 得助（比劫帮身，约15%）

四柱中有比肩或劫财帮身：
- 比劫在日支 → 力量最大
- 比劫多则帮身力大
- 比劫有根则有力

## 旺衰判断流程

1. **先看月令**（得令否）→ 定基调
2. **次看地支**（得地否）→ 定根基
3. **再看印星**（得生否）→ 定助力
4. **后看比劫**（得助否）→ 定强弱
5. **统筹衡量**：得令+得地+得生+得助 → 身旺；反之身弱
6. **特殊格局**：从旺、从弱、化气等（高级判断）

## 身旺判断条件

邵伟华总结：
1. **得令是身旺最重要条件**
2. 得令前提下，得地/得生/得助再占其一 → 身旺
3. 不得令情况下，得地/得生/得助占二项以上且有力 → 身旺
4. 不得令情况下，三合或三会为生身之局 → 身旺

## 身弱判断条件

身弱的判断从身旺的反面理解：
- 不得令、不得地、不得生、不得助 → 明确身弱
- 得令但克泄耗远大于生助 → 旺而不旺

## 日干五行取用宜忌

| 日干 | 旺时宜 | 衰时宜 |
|------|--------|--------|
| 木 | 火泄、金克 | 水生、木扶 |
| 火 | 土泄、水克 | 木生、火扶 |
| 土 | 金泄、木克 | 火生、土扶 |
| 金 | 水泄、火克 | 土生、金扶 |
| 水 | 木泄、土克 | 金生、水扶 |

## 注意事项

- 五阴干与五阳干的十二长生方向不同，判断旺衰时需注意
- 用神取错全盘皆错，旺衰判断是最关键的第一环
- 复杂在于对日干以外干支的强弱、远近、生克、冲合的综合判断
