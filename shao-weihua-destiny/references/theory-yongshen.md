# 用神选取理论

> 蒸馏自邵伟华《四柱预测学》第7章

## 用神概念

- **用神**：命局中最需要的五行，能使命局趋于平衡
- **喜神**：生用神的五行（帮助用神）
- **忌神**：克制用神的五行（损害用神）
- **仇神**：生忌神的五行（间接损害用神）

用神健全有力与否，影响人一生的命；用神补救与否，影响人一生的运。

## 用神三原则

### 1. 扶抑法

**身弱**：取生扶之十神为用
- 取**印星**（生我者）为用神 → 泄官杀、生身
- 无印星则取**比劫**（同我者）为用 → 助身

**身旺**：取克泄耗之十神为用
- 取**官杀**（克我者）为用 → 抑身
- 取**食伤**（我生者）为用 → 泄身
- 取**财星**（我克者）为用 → 耗身

**身弱细分**：
- 多官杀 → 取印星（泄官生身）
- 多财星 → 取比劫（抑财助身）
- 多食伤 → 取印星（抑食伤生身）

**身旺细分**：
- 多印星 → 取财星（抑印耗身）
- 多比劫 → 取官杀（抑比劫旺身）

### 2. 通关法

命局两种五行对立相战时，取能化解的五行通关。

**通关对照**：
| 相战 | 通关五行 | 原理 |
|------|---------|------|
| 火金相战 | 土 | 火生土、土生金 |
| 水火相战 | 木 | 水生木、木生火 |
| 金木相战 | 水 | 金生水、水生木 |
| 土水相战 | 金 | 土生金、金生水 |
| 木土相战 | 火 | 木生火、火生土 |

通关条件：通关五行须有根有力，否则无法化敌为友。

### 3. 调候法

天道有寒暖，人采天地之气，离不开寒暖燥湿影响。

**调候规则**：
- **夏月**（巳午未月）：偏暖过燥 → 取**水**调候降温
- **冬月**（亥子丑月）：偏寒过湿 → 取**火**调候暖局
- **春秋月**：寒暖适候 → 无需特别调候，只论五行生克制化

调候须与扶抑一并参断，不能单独使用。

## 用神选取优先级

1. **调候**（太寒太热时优先）
2. **通关**（五行对立时）
3. **扶抑**（常规旺衰失衡）

## 用神救应

用神受损时的补救措施：
- **用神被克** → 需有救应（生用神的五行出现）
- **用神被合** → 需有冲合之神解救
- **用神入墓** → 需有冲墓之神

## 用神喜忌主事

| 十神 | 为喜用神时 | 为忌神时 |
|------|-----------|---------|
| 正官/七杀 | 贵人提扶、升官、中榜 | 官符刑克、牢狱之灾 |
| 正印/偏印 | 功成名就、晋升得权 | 身体失和、失位丧权 |
| 比肩/劫财 | 夺利得财、手足扶助 | 妻财有损、手足失和 |
| 食神/伤官 | 得子延寿、才华发挥 | 子女拖累、降职免位 |
| 正财/偏财 | 娶妻纳妾、财利可得 | 财多身弱、为财困扰 |

## 注意事项

- 正官、正印、正财、食神为吉神，但组合不好或偏枯则不吉
- 伤官、偏财、偏印、七杀、比劫为破败之神，但组合好反而为吉
- 用神是根据每个人不同的四柱组合来定的，没有固定公式
