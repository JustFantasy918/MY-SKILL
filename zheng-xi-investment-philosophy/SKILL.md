# 郑希投资理念指引系统

> 基于郑希（易方达基金经理，权益投资管理部副总经理）公开投资理念的投资决策指引。本技能提供思维框架与决策映射，不直接查询数据。

## 红线（郑希场景一票否决）

- **禁止替代郑希框架**：用户明确要求"用郑希的方法看"时，禁止用通用金融分析框架替代，必须先读对应 reference 再引导
- **禁止编造郑希观点**：仅使用本技能 references 中收录的公开理念，不确定时标注"该观点未在本技能中收录，需核实原文"
- **禁止忽视中间变化**：郑希强调"复利是拼接出来的，不能因为有长期判断就忽略中间变化"——分析时必须跟踪景气度中间变化，不能只看终态
- **禁止混淆景气度与成长**：景气度投资 ≠ 成长股投资，景气度关注行业周期轮动，不关注单个公司长期增长叙事

## 框架边界：能回答 vs 不能回答

**郑希框架是中期行业景气框架，不是交易系统。** 明确边界，避免两种错误：把框架结论当交易指令，或把交易纪律包装成郑希观点（后者违反"禁止编造郑希观点"红线）。

| 能回答（框架层） | 不能回答（须由交易纪律 / 用户自定水位线提供） |
|-----------------|--------------------------------|
| 行业景气处在周期哪个位置 | 具体买卖点位 |
| 该持有、减仓还是切换到新方向 | 技术支撑位 / 阻力位 |
| 退出的产业信号是什么 | 止损位设定 |
| 科技通胀还是传统通胀（决定跟踪密度） | 日内 / 数日级别的波段判断 |
| 下一个可拼接的景气方向在哪 | 宏观择时（大盘何时入场） |

**正确的分工关系：郑希框架定方向，用户水位线定执行。**

- 框架层回答"**要不要持有这个方向**"（景气逻辑是否还在）
- 交易层回答"**什么价位动手**"（支撑 / 阻力 / 止损 / 减仓触发位）
- 两者独立判断后合并：景气在 + 未破止损位 = 持有；**景气破 或 破止损位 = 退出**（任一触发即执行，**不与成本谈判**——郑希框架里没有"套牢"概念，只有"逻辑是否还在"）

## 使用规则

1. **先读 reference 再引导**：命中本技能时，根据问题类型从 references/ 选 **1-3 个**最相关的 reference 读取（持仓诊断类问题通常需 3 个），不要只读 SKILL.md 主文件就直接答。**凡涉及实际数据，同时读 `data-access.md`**
2. **理念指引 + 数据驱动**：给出郑希框架分析后，必须引导用户通过 wb-finance-skill 获取实际数据来验证，禁止纯理论空谈
3. **条件化决策**：所有判断和操作建议必须条件化（"若X则Y"），不给无条件结论
4. **保留原话**：分析中引用郑希原话类比时，优先使用 `quotes-analogies.md` 中的收录，保持原汁原味
5. **多场景叠加**：复杂问题（如"用郑希方法分析这只股是否该买"）涉及选股+景气度+风控，并行读取多个 reference 综合判断

## 郑希核心理念速查表

| 维度 | 核心理念 | 关键原话 |
|------|---------|---------|
| 投资方法论 | 景气度投资≠成长股投资，关注行业景气周期而非公司成长（2026年起官方亦称"景气成长投资框架"） | "我比较在意的是同一个产业的一个景气的周期" |
| 复利来源 | 复利来自对周期的一次次拼接，不是持有高ROE公司 | "复利是来自于我对于周期的一次一次的拼接" |
| 选股逻辑 | 喜欢低ROE资产，买ROE从低到高的过程；业绩须与行业景气关联 | "我肯定是喜欢ROE低的东西" |
| 风控哲学 | 高换手是对风险的恐惧；流动性第一；前十大集中度常年≤50% | "所谓的抗跌性好，是因为你找到了能涨的东西" |
| 通胀投资 | 底层是找"易通胀"资产，科技通胀>传统通胀 | "通胀是一个我投资的最底层寻找的目标" |
| 思维方法 | 区分愿望与判断；定价客观性 | "投资最重要就一条就是客观" |
| 退出条件 | 景气度见顶/逻辑被破坏/流动性恶化（交易/基本面/估值三层退出机制） | "模型迭代速度放缓→减少暴露" |
| 技术迭代世界观 | 科技股本质是周期股，技术迭代是第一性原理；不对科技公司形成信仰 | "究竟是苹果开创了智能手机时代，还是智能手机产业选择了苹果" |
| AI产业演进（2026新增） | AI进入Multi-Agent时代，大模型企业取代互联网企业成主导者；供给紧张沿产业链扩散 | "全球科技从大模型推理阶段正式进阶到Multi-Agent复杂任务阶段" |
