# 数据获取指引：路由优先 + HTTP 降级

> **何时参考**：任何需要实际数据的场景（行情/财务/景气指标/海外映射/宏观传导）。本文件是郑希 skill 的统一取数入口——各 reference 的"数据查什么"小节均指向本文件。

## 核心目标

**解决"命令跑不通"的问题**。本 skill 的分析离不开数据，但数据工具的可用性随环境变化（MCP 连接器可能未连接、接口可能失效）。本文件给出三级取数策略 + 已验证可用的接口清单。

> **建立说明（2026-09-05）**：原各文件"数据查什么"直接调用 `westock-data` / `westock-tool` / `neodata` 命令。实测这三者为 MCP 工具，当前环境未连接（`command -v westock-data westock-tool neodata` 均无返回），命令无法执行——2026-09-01 的两次实战分析实际是走免费 HTTP 接口完成的。本文件补齐降级方案，避免每次靠临场找接口。
> 接口清单于 **2026-09-01** 实测验证可用。

---

## 一、三级取数策略

| 级别 | 方式 | 优先级 | 说明 |
|------|------|--------|------|
| **L1 路由层** | 加载 `wb-finance-skill` | 最先 | 金融场景总入口，由其路由表决定当前可用的数据源（westock / neodata / tdx 等） |
| **L2 命令层** | `westock-data` / `westock-tool` / `neodata` | L1 路由成功时 | 命令见各 reference"数据查什么"；**执行前先确认可用**：`command -v westock-data` |
| **L3 降级层** | 免费 HTTP 接口（curl） | L1/L2 不可用时 | 见第二节，覆盖实时行情 / K线 / 海外指数 / 商品贵金属 |

**执行流程**：

1. 命中郑希 skill 且需要数据 → 先走 **L1**（加载 wb-finance-skill），按其路由表选源
2. 命令行工具可用（`command -v` 有返回）→ 用 **L2**
3. 工具不可用 / 无返回 / 命令报错 → **直接降 L3**，不要反复重试
4. 资讯类与景气数据（行业价格、订单、产能、资本开支、模型迭代）→ **WebSearch，必须带 freshness**

## 二、已验证可用的免费接口（2026-09-01 实测）

### 1. A股实时行情（腾讯）

```bash
curl -s -A "Mozilla/5.0" "https://qt.gtimg.cn/q=sh000688,sh512760,sh000001,sz399006" | iconv -f GBK -t UTF-8
```

- 代码前缀：沪市 `sh`、深市 `sz`。常用指数：科创50 `sh000688`、上证 `sh000001`、创业板 `sz399006`、深成指 `sz399001`
- **返回为 GBK 编码，必须 `iconv -f GBK -t UTF-8`**，否则中文乱码
- 返回字段含：现价、昨收、今开、成交量、涨跌额、涨跌幅、最高、最低、成交额、时间戳

### 2. A股日K线（腾讯）

```bash
curl -s -A "Mozilla/5.0" "https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh512760,day,,,40,qfq"
```

- 参数格式：`代码,周期(day/week/month),,,条数,复权(qfq前复权)`
- 用途：画水位线图、判断支撑阻力位、观察量能变化（郑希流动性跟踪的核心数据）

> **⚠️ 两个实测坑（2026-09-06 复核）**：
>
> **1. 返回字段名随标的类型变化，不能写死解析 `qfqday`**
> - A股个股 + `qfq` → 字段为 **`qfqday`**
> - A股**指数**（如 `sh000688`）→ 字段为 **`day`**（指数无复权概念，即使传了 `qfq`）
> - 若代码固定取 `qfqday`，查指数会取到空。**解析时按"取返回对象中第一个数组"处理更稳**。
>
> **2. 美股代码条数参数失效，不可用于画 K 线**
> - 实测 `param=usNVDA,day,,,6,qfq` 请求 6 条，**只返回 2 条：`2011-06-02` 与最新一日**——返回的是历史首末两条而非最近 6 日
> - 该接口**仅限 A 股/指数使用**；美股走势请改用实时行情接口（第二节第 4 条）取单点，或走 L1/L2

### 3. 美股指数（含费城半导体，新浪）

```bash
curl -s -A "Mozilla/5.0" -H "Referer: https://finance.sina.com.cn" "https://hq.sinajs.cn/list=gb_sox"
```

- **`gb_sox` = 费城半导体指数**——郑希框架下最关键的海外映射指标
- **必须带 `Referer: https://finance.sina.com.cn`**，否则返回空
- 同系列：`int_nasdaq`、`int_sp500`、`int_dji`

### 4. 美股个股（腾讯）

```bash
curl -s -A "Mozilla/5.0" "https://qt.gtimg.cn/q=usNVDA,usMU,usTSM,usLRCX,usASML,usAMD,usAVGO"
```

- 格式：`us` + 代码
- 郑希 QDII 重仓相关：`usLRCX`（拉姆研究/泛林，2026Q2 第一大重仓）、`usASML`（阿斯麦）、`usTSM`（台积电）、`usMU`（美光）、`usAMD`、`usAVGO`（博通）

### 5. 外盘商品与贵金属（新浪）

```bash
curl -s -A "Mozilla/5.0" -H "Referer: https://finance.sina.com.cn" "https://hq.sinajs.cn/list=hf_XAU,hf_CL,hf_OIL"
```

- `hf_XAU` 伦敦金现货、`hf_CL` 纽约原油(WTI)、`hf_OIL` 布伦特原油
- 用于观测宏观传导链：**油价 → 通胀预期 → 美债收益率 → 加息预期 → 科技股估值**（详见 risk-management.md 第四维度）
- 兼用于黄金持仓（如黄金 ETF）的联动判断

### 6. 东方财富（备用源，不可作为唯一来源）

```bash
curl -s -A "Mozilla/5.0" "https://push2his.eastmoney.com/api/qt/stock/kline/get?secid=1.512760&fields1=f1,f2,f3&fields2=f51,f52,f53,f54,f55,f56,f57&klt=101&fqt=1&end=20500101&lmt=40"
```

- `secid` 规则：`1.` 沪市、`0.` 深市
- ⚠️ **2026-09-01 实测 `push2` 接口空返回**，`push2his` 时好时坏。必须带 User-Agent，且**永远准备备用源**

**量比计算（风控必做，不可只看绝对成交额）**：

K线接口返回的数组第 6 位是**成交量（手）**。量比 = 当日 / 前 5 日均量：

```python
import json, urllib.request
req = urllib.request.Request("https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh512760,day,,,20,qfq",
                             headers={"User-Agent":"Mozilla/5.0"})
d = json.load(urllib.request.urlopen(req))["data"]["sh512760"]
arr = d.get("qfqday") or d.get("day")      # 字段名随类型变，两个都试
vol = [float(r[5]) for r in arr]
r5 = vol[-1] / (sum(vol[-6:-1]) / 5)       # 量比5：标准基准
r2 = vol[-1] / (sum(vol[-3:-1]) / 2)       # 量比2：敏感基准
tag = lambda r: "放量" if r > 1.5 else "缩量" if r < 0.7 else "常态"
print(f"量比5 {r5:.2f}({tag(r5)})  量比2 {r2:.2f}({tag(r2)})")
# 两基准冲突时取更敏感者：量比2 放量 → 按放量处理
print("判定:", "放量" if (r5 > 1.5 or r2 > 1.5) else "缩量" if (r5 < 0.7 and r2 < 0.7) else "常态")
```

判读标准与四象限处置见 `risk-management.md` 退出条件3。**量比 >1.5 且下跌 = 放量破位**，是最易漏掉的危险信号。

> ⚠️ **必须算两个基准**（2026-09-06 实测教训）：只看量比5 会漏掉"前几日缩量后的急性放量"——2026-09-04 的 512760 量比5 仅 1.40（常态）但量比2 达 1.68（放量），实为放量破位。**冲突时取更敏感者。**

## 三、WebSearch 使用规范（重要）

- **必须带 `freshness` 参数**：`d1`（当日）、`d2`（近两日）、`m1`（近一月）
- ⚠️ **踩坑记录（2026-09-01）**：搜索"9月1日 A股科技股大跌原因"未加时间过滤，返回结果混入了 **2025-09-01 的旧闻**（同月同日，但点位与行情完全不同），险些导致错误归因。**凡涉及"今日/昨日"的行情归因搜索，一律加 freshness**
- 数据型搜索优先官方源 / 权威媒体，**两条以上来源交叉验证**后再写入结论
- 郑希本人观点类搜索 → 见 `zheng-xi-skill-update-check` skill 的 data-sources.md

## 四、郑希视角的分场景取数对照

| 场景 | 需要的数据 | 取数路径 |
|------|-----------|---------|
| 景气位置判断 | 行业价格 / 产能 / 库存 / 订单 | WebSearch（带freshness）+ L1/L2 |
| ROE 趋势 | 个股多期财务 | L1/L2。**注意**：neodata 默认只返回约 3 年，判断周期位置须主动写"近 10 年" |
| 持仓水位线 | 实时行情 + 日K线 | L3 腾讯实时 + K线接口 |
| 量能跟踪（郑希风控第一指标） | **量比** = 当日成交量 / 前5日均量 | L3 K线接口成交量字段（第6位），**必须自行计算量比**，见下方"量比计算" |
| 海外映射 | 费半 / 纳指 / 美股半导体个股 | L3 新浪 `gb_sox` + 腾讯 `us` 代码 |
| 宏观传导 | 油价 / 金价 / 美债收益率 / 加息预期 | L3 新浪 `hf_` 系列 + WebSearch |
| 景气资讯 | 模型迭代 / 资本开支 / DRAM 报价 | WebSearch（带freshness） |

## 五、坑与注意事项（速查）

1. 腾讯 / 新浪接口返回 **GBK** → 必须 `iconv -f GBK -t UTF-8`
2. 新浪外盘与美股指数需 **Referer 头**
3. 东财接口需 **User-Agent**，且不稳定 → 必有备用源
4. WebSearch **必须加 freshness** → 否则混入历史同期旧闻
5. 取数失败 → **换源**，不反复重试同一接口
6. 所有数据须记录 **来源 + 获取时间**；超过 90 天标 `[STALE]`（见下）

## 六、数据时效标注规范

写入分析结论的数据型陈述，必须带来源与获取日期，格式：

```
（数据来源：TrendForce，2026-08-31 获取）
```
