# 决策映射工作流

> **何时参考**：用户问"帮我按郑希思路做个投资决策 / 用郑希框架分析这只股 / 郑希会怎么操作 / 按景气度投资做交易计划 / 郑希方法做投资分析"。

## 核心目标

**提供从"郑希理念"到"具体行动"的完整映射链路**——理念→数据→判断→操作，每一步都是条件化的。这是郑希方法的终极实操指南。

---

## 一、完整决策流程图

```
用户提出投资问题
    │
    ▼
[Step 1] 确定分析维度 → 读对应 reference
    ├─ 选股问题 → stock-selection-framework.md
    ├─ 景气判断 → prosperity-cycle-guide.md
    ├─ 风控问题 → risk-management.md
    ├─ 板块问题 → sector-views.md
    ├─ 理念理解 → core-philosophy.md
    └─ 综合决策 → 本文件（+ 多个 reference 并行读取）
    │
    ▼
[Step 2] 确定景气度位置 → 查数据
    ├─ 行业价格/产能/库存/订单趋势
    ├─ 科技行业加查：模型迭代速度/渗透率/资本开支方向
    ├─ 判断通胀类型（科技通胀 vs 传统通胀）
    ├─ 判断景气阶段（下行尾声→底部磨底→上行初期→上行中段→高位见顶→下行初期）
    ├─ 数据命令见各 reference 的"数据查什么"
    │
    ▼
[Step 3] 确定ROE位置 → 查数据
    ├─ 当前ROE水平（低/中/高）
    ├─ ROE趋势方向（下行/持平/上行）
    ├─ 低ROE原因判断
    │   ├─ 类型A：行业弱但公司有竞争力 → 验证同行对比
    │   ├─ 类型B：重投入方向正确 → 验证研发转化信号
    │   ├─ 其他：能力不足/方向错误 → 不值得买
    ├─ 数据命令见 stock-selection-framework.md
    │
    ▼
[Step 4] 综合判断 → 郑希框架下结论
    │
    ├─ 景气上行初期 + 低ROE + 有竞争力 = ★ "郑希最想买"
    │   → 试错仓→确认仓→加仓的渐进路径
    │
    ├─ 景气上行中段 + ROE正在提升 = "持有享受"
    │   → 持有+动态跟踪+注意见顶信号
    │
    ├─ 景气高位见顶 + ROE高位 = "拼接结束，退出"
    │   → 左侧减仓→寻找下一个景气方向
    │
    ├─ 景气不明 + 低ROE = "观察，不急于入场"
    │   → 底部磨底期，等待催化信号
    │
    ├─ 景气下行初期 + ROE开始下降 = "退出信号"
    │   → 退出→降低仓位→防守
    │
    ├─ 科技通胀 = "更密集跟踪"
    │   → 模型迭代速度是核心指标
    │
    ├─ 传统通胀 = "可更多依赖经验"
    │   → 历史周期规律可参考
    │
    ▼
[Step 5] 条件化操作指引
    ├─ 买入条件：哪些数据确认景气反转
    ├─ 仓位建议：试错仓→确认仓→加仓的路径
    ├─ 动态跟踪清单：客户/竞争/供应链三维度
    ├─ 失效条件：哪些数据推翻当前判断
    ├─ 退出条件：景气见顶/逻辑破坏/流动性恶化的具体阈值
    └─ 下一步：如果退出，寻找哪个新景气方向（拼接）
```

## 二、常见场景的决策映射

### 场景A："用郑希方法看这只股"

**步骤**：
1. 读 `stock-selection-framework.md` → 确定是否属于郑希偏好类型
2. 查 ROE 水平+趋势 → 判断是否"低ROE将变好"
3. 查行业景气度 → 判断景气位置（参考 `prosperity-cycle-guide.md`）
4. 查竞争力证据 → 验证低ROE原因（类型A vs 类型B）
5. 查流动性 → 确保退出能力
6. 综合输出：是否值得关注 + 买入条件 + 风控条件 + 退出条件

**决策输出模板**：
```
【景气位置】：上行初期 / 上行中段 / 高位见顶 / 下行初期 / 底部磨底
【ROE判断】：低→高(值得买) / 低→更低(不值得) / 高→更高(已过最佳点) / 高→低(退出信号)
【低ROE原因】：类型A(行业弱公司强) / 类型B(重投入方向对) / 其他(不值得)
【通胀类型】：科技通胀 / 传统通胀 / 混合型 / 无通胀
【操作建议】：试错仓 / 确认仓 / 加仓 / 持有观察 / 减仓 / 退出 / 不入场
【验证条件】：哪些数据变化确认/推翻当前判断
【退出条件】：景气见顶 / 逻辑破坏 / 流动性恶化的具体阈值
【跟踪清单】：客户/竞争/供应链三维度需要持续关注的具体指标
```

### 场景B："XX板块景气度到了什么阶段"

**步骤**：
1. 读 `sector-views.md` + `prosperity-cycle-guide.md`
2. 查行业景气指标 → 判断周期位置
3. 判断通胀类型（科技通胀 vs 传统通胀）→ 决定跟踪密度
4. 输出：景气位置判断 + 验证指标 + 下一步跟踪计划

### 场景C："帮我按郑希思路做交易计划"

**步骤**：
1. 读 `decision-flowchart.md` + `risk-management.md` + `prosperity-cycle-guide.md`
2. 按完整决策流程图执行每一步
3. 输出：条件化交易计划（买入条件/仓位/跟踪/退出）

### 场景D："郑希怎么选低ROE股"

**步骤**：
1. 读 `stock-selection-framework.md` + `core-philosophy.md`
2. 输出理论框架 + 实操指引 + westock-tool 筛选命令示例
3. 用户可选择实际执行筛选 → 调用 westock-tool

### 场景E："我持仓了这些股，郑希怎么跟踪"

**步骤**：
1. 读 `risk-management.md`
2. 按动态跟踪三维度（客户/竞争/供应链）给出每只持仓的跟踪清单
3. 输出：每只持仓的景气度位置 + 验证指标 + 退出条件

## 三、机构→个人的适配规则（2026-09 补齐，框架推演）

> **为什么需要这一节**：郑希的纪律是**数百亿规模、团队调研、日内交易支持**下的产物。个人投资者直接照搬会水土不服。本节给出换算规则。

### 3.1 可直接继承的（无需换算）

| 郑希纪律 | 个人适用性 | 说明 |
|---------|-----------|------|
| 先判断行业景气位置，再看公司 | ✅ 完全适用 | 这是方法论内核，与规模无关 |
| 动态跟踪（客户/竞争/供应链） | ✅ 适用，频率下调 | 个人按月跟踪即可，机构按周/日 |
| 流动性第一 | ✅ 更适用 | 个人一旦买进流动性差的品种更难退出 |
| 左侧退出（信号初现即减仓） | ✅ 完全适用 | 个人更等不起"确认见顶" |
| 不把成本当决策依据 | ✅ 完全适用 | 个人反而更容易犯"等回本"的错 |

### 3.2 需要换算的（不可照搬）

| 郑希机构做法 | 直接照搬的问题 | 个人换算规则 |
|------------|--------------|------------|
| **前十大集中度常年 ≤50%** | 个人资金量小，过度分散会降低收益弹性，且 ETF 本身已分散 | 单一**行业**敞口建议 ≤40-50%；单一 ETF 可达 30-40%（ETF 内部已分散）；单一个股 ≤15-20%。**49% 单一行业 ETF 已触及纪律上限**，正确动作是反弹降敞口而非死扛 |
| **高换手（依赖团队调研）** | 个人无调研支持，高频换手=高频犯错 | 用"**信号触发式调仓**"替代"高频换手"：只在验证点（季报/价格数据/宏观日历）动作，平时不动 |
| **5-10% 试错仓** | 个人资金小，5% 仓位即使翻倍也无意义 | 试错仓可放大到 **10-15%**，但须满足"亏光不影响生活"的绝对前提 |
| **"买的少犯错成本可控"** | 个人容易一次买满 | 建仓分 **2-3 批**，每批间隔一个验证点（如季报、价格数据） |
| **全球配置（QDII/美股/港股）** | 个人换汇/开户/税务成本高 | 用 QDII 基金或跨境 ETF 替代直接持股，方法论照用 |

### 3.3 个人最容易踩的三个坑

1. **把"景气还在"当"不动作的理由"**——郑希同时强调流动性纪律。**景气逻辑决定"要不要持有"，水位线/流动性决定"什么时候动"，两者不互相替代。**
2. **用成本价当决策依据**——"等回本再卖"。郑希框架里没有"套牢"概念，只有"景气逻辑是否还在"。
3. **把愿望当判断**——每次给出结论前，必须写明**证伪条件**（见下方输出模板第六步）。

## 四、仓位管理路径

### 试错仓 → 确认仓 → 加仓

> ⚠️ **标注**：下表的**具体百分比是框架推演，不是郑希原话**。郑希只公开表述过"买的少的话，即使犯错成本相对可控"这一原则，未给出过具体仓位比例。引用时须说明这是推演。

郑希的仓位管理是渐进式的：

| 阶段 | 仓位 | 条件 | 退出触发 |
|------|------|------|---------|
| 试错仓 | 5-10% | 景气方向初步确定+低ROE条件满足 | 景气信号反转/逻辑被证伪 |
| 确认仓 | 15-20% | 景气反转数据确认+ROE开始回升 | 景气见顶信号/流动性恶化 |
| 加仓 | 25-30% | 景气上行中段+ROE持续提升+动态跟踪正常 | 景气增速放缓/库存堆积 |

**重要提醒**：
- 试错仓阶段不要怕犯错——少量仓位+流动性保障=犯错成本可控
- 每个阶段都有独立的退出条件——不是"加仓了就不能减仓"
- 仓位管理是动态的，不是一次设定就不变

## 五、决策输出的条件化格式

所有郑希方法的决策输出**必须条件化**，格式如下：

### 标准输出格式（个股/板块分析场景）

```
## 郑希视角分析：[标的名称]

### 景气判断
- 当前位置：[6阶段之一]
- 通胀类型：[科技通胀/传统通胀]
- 判断依据：[具体数据]
- **若** [景气信号变化] → [操作调整]

### ROE判断
- 当前水平：[低/中/高]
- 趋势方向：[上行/持平/下行]
- 低ROE原因：[类型A/B/其他]
- **若** [ROE信号变化] → [操作调整]

### 操作建议
- 建议：[试错仓/确认仓/加仓/持有/减仓/退出/不入场]
- 仓位参考：[百分比]
- **若** [验证条件确认] → 进入下一阶段
- **若** [失效条件触发] → 立即退出

### 跟踪清单
- 客户维度：[具体指标]
- 竞争维度：[具体指标]
- 供应链维度：[具体指标]

### 退出条件
- 景气见顶：[具体信号阈值]
- 逻辑破坏：[具体证伪条件]
- 流动性恶化：[成交额/换手率阈值]

### 下一步（拼接）
- 若退出，下一个景气方向：[候选板块]
```

## 六、个人投资者持仓诊断输出模板（2026-09 补齐）

> **何时使用**：用户给出实际持仓问"操作思路/要不要减仓/止损/加仓/行情结束了吗"时使用。**这是本 skill 最高频的实战场景**，必须严格按此模板输出——模板要素已从多轮实战中验证为用户的固定偏好，**不得省略**。

### 七步结构（缺一不可）

```
一、结论先行
   - 用表格给出每个标的的：短期（1-4周）/ 中期（1-3月）/ 核心仓位纪律
   - 一句话总定性（如"跌的是资金面不是基本面"）

二、市场现状快照
   - 表格：标的 / 收盘 / 涨跌 / 位置解读
   - **量能必须给"量比"**：当日成交量 / 前5日均量（>1.5 放量，<0.7 缩量）
     并附成交额相对历史高峰的百分比
   - 走势结构判读（双底/破位/反弹高点递减等）

三、郑希框架景气定位
   - 表格：郑希信号（价格趋势/供给紧张/资本开支/模型迭代/海外映射）
     → 最新数据 → 判读（上行初期/中段/高位/见顶）
   - 宏观维度：是否有"中间变化"与郑希判断背离
   - **量能维度（四象限，见 risk-management 退出条件3）**：
     先算量比 → 结合涨跌方向 → 落入哪一格 → 对应处置
     ⚠️ 不可只报"成交额 X 亿"就下结论，必须判方向

四、关键水位线表（每个标的独立一张）
   | 价位 | 性质（阻力/现价/支撑/生命线/止损） | 触发动作 |
   - 阻力位必须给减仓动作；支撑位必须给持有或减仓动作
   - 🔴 = 无条件执行（止损/清仓线）；⚠️ = 警戒（准备动作）
   - **同时给出两类量能阈值**：① 枯竭线（缩量到 X 亿以下 → 优先退出）
     ② 破位确认（放量 >1.5 倍且跌破支撑 → 按水位线减仓）

五、跟踪清单与验证日历
   - 每周盯：量能/流动性修复
   - 每月盯：价格数据、订单、资本开支
   - 验证日历：具体日期 + 事件 + 该事件对框架的意义
   - **任一触发即改变中期策略的触发器清单**

六、"愿望 vs 判断"自检（郑希纠偏方法）
   - 明确回答"我这个结论是愿望还是判断"
   - 必须写明证伪条件：什么情况发生 → 结论翻转 → 对应动作是什么

七、数据与引用说明
   - 数据：来源 + 获取时间（实时接口须注明日期与时间点）
   - 郑希观点：注明出处（季报/专访/手记 + 日期）
   - **框架推演 vs 郑希原话必须分开标注**；媒体解读须注明非原话
   - 若某数据未核实，明确标"待复核"，不得当作确定事实
```

### 硬性要求（实战验证的用户偏好）

1. **加仓策略与减仓/止损策略缺一不可**——只给一侧视为不完整
2. **关键价位必须带 🔴 / ⚠️ 标记**，不得只给文字描述
3. **结论先行**，不要铺垫到最后才给答案
4. 表格优先于段落；条件化表述（"若…则…"）优先于无条件结论
5. 数据源必须免费可查（东方财富/新浪/腾讯），**不得估算或用付费数据**

## 七、决策避坑指南

### 郑希方法中最容易犯的错误

| 错误 | 正确做法 | 原话提醒 |
|------|---------|---------|
| 给无条件结论 | 所有判断条件化 | "复利是拼出来的，不能忽略中间变化" |
| 用通用框架替代郑希框架 | 先读对应 reference 再引导 | "景气度投资≠成长股投资" |
| 只看公司不看行业 | 先判断行业景气位置 | "我比较在意的是产业的景气周期" |
| 追求低换手 | 动态跟踪+动态调整 | "我的换手率就是来自于我非常害怕" |
| 寻找"抗跌资产" | 寻找"下一个能涨的资产" | "抗跌性好是因为你找到了能涨的东西" |
| 右侧退出（等确认才退） | 左侧退出（信号初现即减仓） | "模型迭代放缓→卖出规避风险" |
| 只看ROE高低不看趋势 | 关注ROE从低到高的过程 | "我买的是ROE从低到高的过程" |
| 不分通胀类型 | 先判断科技通胀vs传统通胀 | "通胀是投资最底层寻找的目标" |
| **拿"景气还在"当不动作的理由** | 景气定方向，水位线/流动性定执行 | "流动性第一"（见 `risk-management.md`） |
| **用海外涨跌代替景气判断** | 海外映射是风险偏好信号，景气须回产业数据 | 见 `sector-views.md` 第八节 |
| **把框架推演当郑希原话引用** | 凡推演必标注 | 见各文件标注规范 |
