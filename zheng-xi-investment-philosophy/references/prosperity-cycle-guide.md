# 景气度周期判断实操指引

> **何时参考**：用户问"XX景气度到了什么阶段 / 行业周期拐点 / 景气上行还是下行 / 怎么判断景气度反转 / 郑希怎么判断周期位置 / 景气周期怎么拼"。

## 核心目标

**用郑希的景气度框架判断行业当前处于周期的哪个位置**——这是景气度投资的核心能力，也是所有选股和交易决策的前提。

> 更新说明（2026-08-31）：新增 AI Agent 演进阶段、供给紧张扩散模式作为景气信号；拼接案例更新至2026年上半年（光模块→半导体制造端）；存储合约价纳入验证指标。资料来源：2026年中期报告、2026Q1/Q2季报。

## 一、景气度周期模型（郑希视角）

### 六阶段周期定义

郑希虽然没有明确命名六阶段，但从他的公开表述中可以归纳出以下模型：

| 阶段 | 特征 | 郑希操作倾向 | 关键信号 |
|------|------|-------------|---------|
| 1. 下行尾声 | 行业最差但出现改善信号 | **最想买的阶段**——低ROE+反转信号初现 | 价格触底、库存见底、产能开始出清、个别公司逆势增长 |
| 2. 底部磨底 | 改善信号不明确 | **观察期，不急于入场** | 信号反复、数据摇摆、行业分歧大 |
| 3. 上行初期 | 确认反转，量价开始回升 | **加仓阶段**——ROE开始从低到高爬升 | 订单放量、价格回升、产能利用率提升、ROE环比改善 |
| 4. 上行中段 | 量价齐升，利润持续扩张 | **持有阶段**——享受ROE提升过程 | 行业整体盈利提升、渗透率加速、资本开支增加 |
| 5. 高位见顶 | 增速放缓，库存开始堆积 | **减仓阶段** | 增速环比放缓、库存堆积、价格见顶、同行大规模扩产 |
| 6. 下行初期 | 开始恶化但市场可能还没反应 | **退出阶段**——拼接结束 | 模型迭代放缓(科技)、价格下行、订单缩减、ROE环比下降 |

### 郑希判断周期的独特视角

与通用周期分析的核心差异：

| 维度 | 通用周期分析 | 郑希景气度分析 |
|------|------------|--------------|
| 判断起点 | 看供需数据判断位置 | 先判断通胀类型，再看供需数据 |
| 周期性质 | 不区分周期类型 | 科技通胀周期更爆炸但需更密集跟踪；传统通胀周期更稳健可更多依赖经验 |
| 退出时机 | 右侧退出（确认见顶后） | 左侧退出（见顶信号初现即减仓） |
| 中间跟踪 | 看季度数据 | 高频动态跟踪（客户/竞争/供应链） |
| 周期衔接 | 不考虑衔接 | 主动拼接——退出的同时寻找下一个周期 |

## 二、科技行业景气度特殊判断

科技行业（郑希主战场）的景气度判断有其独特指标：

### 模型迭代速度——最核心的景气信号

郑希用AI模型迭代速度来判断科技景气周期：

> "去年4月份，当我发现模型又开始迭代了，模型加速我觉得就意味着它落地应用需求会大幅的加速。"

- **模型加速** → 景气上行信号 → 增加暴露
- **模型放缓** → 景气见顶信号 → 减少暴露

**实操案例**：
- 2024年模型迭代速度放缓 → 郑希先卖出相关标的规避风险
- 2025年模型再次加速（Deepseek等） → 重新增加暴露

### AI Agent 演进阶段（2026年新增核心信号）

郑希2026年季报中把AI产业演进作为景气判断的核心锚点：

> "全球科技从大模型推理阶段正式进阶到Multi-Agent复杂任务阶段。AI Agent在二季度加速商业落地，AI ARR（年度经常性收入）进入爆发周期，同时AI投资回报率大幅提升，大模型公司盈利拐点大幅提前。"

**阶段判断框架**：
- Chat-Bot（互动工具）→ Agent（执行任务）→ Multi-Agent（复杂任务协作）
- **AI从"与人聊天的互动工具"迭代到"执行复杂任务的生产力工具" = 景气上行确认信号**
- **配套验证**：AI ARR爆发周期 + 大模型公司盈利拐点提前 + 顶尖大模型公司成为全球商业流量入口

**实操含义**：跟踪AI应用商业化数据（ARR、Agent落地案例、大模型公司盈利）与模型迭代速度同等重要——应用闭环是资本开支持续加码的驱动力。

### 供给紧张扩散模式（2026年新增）

郑希观察到科技产业链的供给紧张是**沿产业链扩散**的：

> "瓶颈环节从长上下文推理需求导致的存储、通信紧张，扩散到CPU（中央处理器）、MLCC（片式多层陶瓷电容器）等多种电子元器件，科技产业链全面供给紧张。"

**判断框架**：
- 紧张集中在单一环节（如2026Q1的存储/通信）→ 景气上行早中期
- 紧张扩散到多环节（CPU/MLCC等被动元件）→ 全面供给紧张，景气上行中段
- **跟踪紧张环节的迁移方向 = 跟踪景气传导路径 = 找下一个拼接方向**（2026H1实操：从连接环节→半导体设备/晶圆/存储制造端）

### 渗透率曲线

郑希的三次科技时代划分体现了对渗透率的关注：

> "科技行业发展接近100年，经历三次大周期，每次周期都是人机交互方式的底层革命。"

- PC时代 → 移动互联网时代 → AI/机器人时代
- 每次渗透率从低到高 = 景气上行主升段
- 渗透率接近饱和 = 景气见顶信号

### 巨头资本开支方向

> "全球AI资本开支已经来到万亿美元级别。"

- 巨头资本开支转向 = 行业景气方向转变信号
- AI从消费品变成生产工具 → 资本开支上限打开 → 2万亿/3万亿/5万亿美金都有可能
- 资本开支增加 → 传输比例相对稳定 → 传输市场规模随总开支扩大

### 全球图谱视角

> "其实按照我的方法来，它核心还是那个全球图谱。"

郑希用全球视野来判断景气方向：
- 算力需求 → 传输+计算+存储
- 传输结构：近距离→电路板，中距离→铜线，远距离→光
- 中国在光的全球比较优势 → 选光不是很难的选择

## 三、景气度判断的数据验证清单

### 必查指标（郑希框架优先级排序）

1. **行业价格趋势**（最直接反映）
   - 产品/服务价格持续上涨 → 景气上行确认
   - 价格开始松动/下跌 → 景气见顶/下行信号
   - 命令：neodata "XX行业价格指数近3年趋势"

2. **产能利用率/开工率**（供需平衡）
   - 产能利用率提升 → 供不应求，景气上行
   - 产能利用率下降 → 供过于求，景气下行
   - 命令：neodata "XX行业产能利用率开工率近3年"

3. **库存周期**（供需错配方向）
   - 原材料→中间品→成品的库存链条
   - 库存见底 → 下行尾声信号
   - 库存堆积 → 高位见顶信号
   - 命令：neodata "XX行业库存周期分析"

4. **订单/合同趋势**（景气上行领先指标）
   - 新订单增速上升 → 景气上行领先信号
   - 大客户采购计划明确 → 类型B买入信号
   - 命令：neodata "XX行业订单合同趋势" 或 `westock-data news <code>`

5. **ROE行业趋势**（景气度综合反映）
   - 行业整体ROE从低开始回升 → 上行初期确认
   - 行业整体ROE高位开始下降 → 下行初期信号
   - 命令：`westock-data finance <代表性公司> --num 8`

### 科技行业额外指标

- **模型迭代速度**：WebSearch "AI大模型最新迭代进展"
- **AI Agent商业化进度**：WebSearch "AI Agent 商业化 ARR 大模型公司盈利"（2026年新增）
- **存储/元器件价格**：WebSearch "DRAM合约价 季度环比" / "MLCC 被动元件 涨价"（供给紧张扩散信号，2026年新增——DRAM合约价2026Q1环比涨90-95%、Q2涨58-63%）
- **渗透率数据**：WebSearch "XX技术渗透率最新数据"
- **资本开支方向**：neodata "全球AI巨头资本开支计划"
- **竞争格局变化**：neodata "XX行业竞争格局最新变化"

### 数据获取命令汇总

```bash
# 行业景气度宏观指标
westock-data macro indicator gdp --year 2025           # 宏观背景
westock-data sector constituent <板块代码>               # 板块成分股

# 个股ROE趋势（判断从低到高）
westock-data finance <code> --num 8                     # 财务多期数据
neodata "XX近10年ROE营收净利毛利率历年"                  # 长周期数据

# 板块资金流向验证
westock-data asfund <代表股>                             # 资金方向
```

## 四、景气度拼接实操

### 从一个周期到下一个周期

郑希的"复利拼接"在实操中的体现：

1. **当前周期见顶信号出现** → 同步寻找下一个景气上行的行业
2. **不是"卖掉等机会"** → 而是"卖A的同时可能已在买B"
3. **拼接效率**取决于对多个行业景气度的同步跟踪能力

### 拼接成功案例：郑希的操作脉络（更新至2026H1）

从郑希2024-2026年的实际操作中可以看到拼接的典型路径：

- 2024年Q1：切入光模块赛道（AI景气上行初期）
- 2024年：模型迭代放缓 → 先卖出相关标的规避风险（拼接中断也是拼接的一部分）
- 2025年Q1：切换至国产算力（不同景气子方向）
- 2025年Q2：海外算力景气度回升 → 加仓
- 2025年Q3：个股景气度分化 → 第一大重仓从新易盛调整至中际旭创
- 2026年Q2：**从"连接环节"向"制造端"拼接**——A股前十大换5只（新进三环集团、生益科技、寒武纪、华虹半导体、中微公司）；QDII前十大换7只（拉姆研究登顶第一大重仓、新进阿斯麦、铠侠、AMD）
- 2026H1：提升AI算力、半导体行业配置比例，降低软件、消费电子配置比例

**拼接逻辑的演进**：2023-2025年押注AI的"连接环节"（光模块），2026年起沿产业链传导路径移向"制造端"（半导体设备、晶圆厂、存储）——供给紧张在哪里扩散，筹码就往哪里迁移。

**每一步都是对景气度中间变化的动态调整，不是一次买入后持有不动。**

### 拼接失败的处理

> "焦虑过程、平静结果"

- 找不到下一个景气上行行业 → 降低仓位，防守为主
- 拼接判断错误 → 快速止损退出（高换手是风控手段）
- 拼接期间的焦虑是正常的 → 过程紧张跟踪，结果坦然接受

## 五、景气度判断的避坑指南

### 常见错误

1. **只看终态不看过程**：判断"这个行业长期会好"后忽略中间变化 → 违反"复利=拼接"
2. **混淆景气度与成长**：因为公司好就认为景气好 → 景气看行业不看公司
3. **右侧等待确认**：等确认见顶才退出 → 郑希是左侧退出
4. **忽视通胀类型**：不分科技通胀与传统通胀 → 跟踪密度和判断方法不同
5. **单一指标判断**：只看一个指标 → 必须多维度交叉验证

### 郑希的纠偏方法

> "我要分辨出来这到底是我的一个愿望还是一个判断。"

- 判断出现偏差时 → 回到客观思维，获取更多实实在在的信息
- 不固执于自己的定价 → 对比同行/市场/公司的定价
- 不害怕认错 → 高换手意味着愿意快速调整
