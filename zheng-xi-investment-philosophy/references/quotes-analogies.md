| 原话 | 含义 | 实操指引 |
|------|------|---------|
| "复利是来自于我对于周期的一次一次的拼接" | 复利不是持有优秀公司赚ROE，而是拼接景气周期 | 每段景气周期独立评估，不假设无限延续；退出时寻找下一个周期 |
| "再长的判断也是有很短的判断拼接起来的" | 不因长期看法忽略中间变化 | 必须密集跟踪中间变化，不能因为"长期看好"就锁仓不动 |
| "我比较在意的是同一个产业的一个景气的周期" | 景气度投资关注行业周期，不关注公司增长 | 选行业优先于选公司；先判断景气位置再判断个股 |
| "景气度投资，不是成长股投资" | 景气度≠成长股，核心区别是看行业不看公司 | 不用成长股框架替代景气度框架 |
| "通胀是一个我投资的最底层寻找的目标，核心就是通胀怎么来的问题" | 底层逻辑是找"易通胀"资产 | 先判断通胀类型（科技/传统），再判断景气位置 |

## 二、选股类

| 原话 | 含义 | 实操指引 |
|------|------|---------|
| "我肯定是喜欢ROE低的东西" | 买低ROE（将变好），不买高ROE（已变好） | 筛选低ROE+景气反转证据，不追求高ROE |
| "我买景气的周期的股票，只买的是一个ROE从低到高的过程" | 买ROE变化过程，不是ROE状态 | 关注ROE趋势方向，不只看ROE绝对水平 |
| "行业很差导致他ROE很低，并不代表他只能做到这么低的ROE" | 类型A：行业弱但公司有潜力 | 验证同行对比——同行低但目标公司相对更高 |
| "它的ROE低是因为它在这之前做了大量的预先性研发，投入方向跟后面景气方向一致" | 类型B：重投入方向对 | 验证研发投入方向+转化信号 |
| "小公司一般ROE都是比较低的，碰上一个好的产业周期的时候，基数小利润放大倍数更大" | 中小盘弹性更大 | 景气反转时中小盘回报更爆炸（前提：景气方向确定） |

## 三、风控类

| 原话 | 含义 | 实操指引 |
|------|------|---------|
| "所谓的抗跌性好，是因为你找到了能涨的东西，而不是说它真的抗跌" | 防守来自切换能力，不是资产本身抗跌 | 不配置低波动资产做防守，找下一个景气方向 |
| "焦虑过程、平静结果" | 过程紧张跟踪，结果坦然接受 | 动态跟踪是日常工作，不是额外负担；对结果不强求 |
| "我的换手率就是来自于我非常害怕" | 高换手是对风险的恐惧和尊重 | 犯错时能快速退出比长期持有更重要 |
| "我会很关注流动性……一定程度上是保护了我撤出的时候的代价" | 流动性第一：确保退出能力 | 买入前先确认能不能卖出；流动性恶化时优先退出 |
| "如果买的少的话，你即使犯错可能成本相对可控" | 试错仓控制犯错成本 | 先少量试错，确认后加仓，不是一次性重仓 |
| "实际上我早就准备好被淘汰了……我只是想在我被淘汰之前做的好一点" | 接受不确定性，追求过程而非极致结果 | 不追求排名前列，做好过程就够了 |

## 使用建议

1. **分析中引用原话时，同时解释其实操含义**——不要只当口号引用
2. **原话是"记忆锚点"**——帮用户快速记住对应的投资逻辑
3. **不同场景选择不同原话**：
   - 选股场景 → 选股类原话（低ROE、基数小乘数大）+ 苹果类比（行业牛vs公司牛）
   - 风控场景 → 风控类原话（抗跌性、流动性、换手率）
   - 景气判断 → 市场时机类原话（模型迭代、全球图谱）+ AI产业演进类（Agent阶段、供给紧张扩散）

   - 板块切换 → AI产业演进类（紧张扩散路径）+ 媒体解读类（连接→制造，需标注）
4. **不确定是否是郑希原话时，标注"该观点未在本技能中收录，需核实原文"**——不编造
5. **原话与媒体解读严格区分**——第七、八节为原话/官方表述，第九节为媒体解读
