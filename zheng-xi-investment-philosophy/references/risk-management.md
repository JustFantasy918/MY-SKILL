# 风险管理与动态跟踪体系

> **何时参考**：用户问"郑希怎么做风控 / 怎么跟踪持仓 / 什么时候退出 / 换仓频率 / 郑希为什么换手率高 / 流动性优先 / 抗跌性 / 郑希风险管理"。

## 核心目标

回答三件事：**郑希风控体系的核心原则、动态跟踪的具体方法、退出条件的判断标准**。

---

## 一、风控核心原则

### 1. 高换手 = 对风险的恐惧和尊重

> "怕当然是怕，所以我会很关注这个东西。其实我的换手率就是来自于我非常害怕。"

**关键理解**：
- 换手率高**不是因为看错**，而是因为尊重风险
- 世界变化太快，尤其科技行业——不能"锁仓不动"
- 换手率高是**动态跟踪的必然结果**，不是投资风格缺陷

> "因为我认为无法预判，就我认为世界变化太快了，尤其是像我喜欢的像技术驱动的行业，就是我觉得变化太快了。"

**实操含义**：
- 使用郑希方法时，不要追求低换手——动态调整是核心方法论
- 不要因为"频繁操作"而怀疑方法论本身——这是郑希刻意选择的风控手段
- 但频繁操作的前提是**有信息驱动**，不是情绪驱动

### 2. 流动性第一原则

> "我会很关注流动性。第一个流动性，其这就成交量和流动性都是很好的，所以它一定程度上是保护了我撤出的时候的代价。"

**核心逻辑**：
- **买入前先确认能不能卖出去**——"先想退出再想买入"
- 流动性好 → 犯错时能退出 → 风险可控
- 流动性差 → 犯错时可能出不来 → 风险不可控

**实操筛选**：
- 确保目标标的日均成交额足够（建议 >5000万）
- 避免买入流动性恶化的标的（成交量萎缩/换手率骤降 → 流动性预警）
- 流动性出问题时**优先退出**——不等景气判断再做决定

> ⚠️ **完整判读见"退出条件3：量价四象限"**。本节只讲"**能不能卖出去**"（买入前筛选 + 枯竭预警）；**持有期的量能信号**必须看四象限——尤其注意**放量下跌不属于流动性问题，而是破位信号**，按水位线减仓，勿与"流动性恶化"混淆。

**A股 vs 其他市场的流动性差异**：

> "A股即便是很小的公司，它还是会有流动性。因为只要有流动性，你就不会出不来。"

- A股中小盘流动性有保护 → 风控底线有保障 → 这是超额收益来源之一
- 港股小盘流动性差 → 需要更谨慎

### 3. 分散持仓逻辑

郑希持仓集中度低于很多成长股基金经理。这不是"不确定"，而是方法论要求：

- 景气度投资本质是概率游戏——单一行业景气判断可能错
- 分散降低单点失败伤害
- 但分散不是漫无目的——每个持仓都有独立的景气逻辑

**数据佐证（2026-08新增，上海证券报专访披露）**：前十大重仓股集中度**常年保持在50%以内**；郑希淡化仓位管理，转而**通过调整行业比例来平衡风险**。

> "分散既是对风险的抵御，也是对机会的储备。"（上海证券报专访）

### 4. "抗跌性来自找到能涨的东西，不是真的抗跌"

> "所谓的抗跌性好，是因为你找到了能涨的东西，而不是说它真的抗跌。"

**核心理解**：
- 不寻找"抗跌资产"（低波动/高分红），而是寻找"下一个能涨的资产"
- 抗跌是**结果**（因为找到了新增长点），不是**目标**
- 持仓的防御性来自**切换能力**，不是资产本身的低波动

**实操含义**：
- 当持仓抗跌性好时 → 不是资产本身抗跌，而是你找到了景气方向 → 继续深挖
- 当持仓开始跌时 → 不是"防御不够"，而是景气逻辑可能出问题 → 检查逻辑
- 不配置"防御性资产"来控制回撤 → 而是通过切换到新的景气方向来"进攻性防守"

## 二、动态跟踪维度（产业三维 + 宏观一维）

### 郑希的跟踪方法论

> "但是不代表我在中间没有跟踪或者没有交易。其实如果买的少的话，你即使犯错可能成本相对可控。那么我就从两个维度去考虑。"

> **表述说明**：郑希原话为"两个维度"，下述**产业三维度（客户/竞争/供应链）是对其跟踪体系的归纳**，非其逐字表述；**第四维度"宏观中间变化"是实战补齐，不是郑希公开的跟踪维度**——加入它是因为实践中发现仅有产业维度会导致误判（见该节说明）。引用时须区分。

郑希对持仓的动态跟踪以产业维度为主：

### 维度1：客户维度

**跟踪内容**：
- 客户需求变化 → 订单/合同趋势 → 景气度验证
- 客户预算方向 → 行业景气方向信号
- 大客户动向是领先指标

**数据获取**：
```bash
# 客户维度数据
neodata "XX公司主要客户订单合同趋势"
westock-data news <code> --limit 10       # 公司新闻动态
```

### 维度2：竞争对手维度

**跟踪内容**：
- 同行动作反映行业真实状态
- 同行扩产 → 景气可能见顶（供给增加，未来供需可能逆转）
- 同行减产/退出 → 景气可能见底（供给出清，未来供需可能好转）

**数据获取**：
```bash
# 竞争对手维度数据
neodata "XX行业同行产能扩产计划"
westock-data profile <同行代码>          # 同行经营状态
westock-data sector constituent <板块>   # 同行列表
```

### 维度3：供应链维度

**跟踪内容**：
- 上游价格变化 → 成本端景气信号
- 中游库存变化 → 供需平衡信号
- 下游订单变化 → 需求端景气信号

**数据获取**：
```bash
# 供应链维度数据
neodata "XX行业上游价格中游库存下游订单趋势"
westock-data sector constituent <板块>   # 产业链映射
```

### 维度4：宏观中间变化（2026-09 实战补齐，非郑希公开的跟踪维度）

**为什么必须补这一维**：前三维全部是**产业层面**。但科技股是长久期资产，对贴现率与流动性高度敏感——实践中反复出现"**产业景气没变、股价却大跌**"的情形。

> **实战案例（2026-09-01 美东 22:00 盘中数据，非收盘）**：当晚费半 -2.74%、泛林（郑希 QDII 第一大重仓）-3.32%、阿斯麦 -1.84%，而**台积电仅 -0.17%**、DRAM 涨价逻辑未变、无模型迭代放缓信号。若只有产业三维度，很容易误判为"景气见顶"而错误退出；实际这是**油价↑ → 通胀预期↑ → 美债收益率创年内新高 → 加息预期↑ → 杀估值**的宏观传导。
>
> **⚠️ 案例后续（2026-09-06 复盘，重要方法论教训）**：该案例的**定性方法成立，但短期走势判断被证伪**——
> - 定性正确：随后的产业数据（DRAM Q3 仍涨 13-18%、云厂商 capex +98%）证明确实不是景气见顶
> - 但路径错误：**费半 9月4日已反弹至 11735（+3.37%），而 A 股芯片 ETF 同期从 1.091 跌至 1.036（-5%）**，跌破原设定支撑带
> - **教训**：宏观定性（跌估值端）**不等于**短期不会继续跌。估值端压力可以持续数周，且 A 股受本土资金主导，与海外反弹可以完全背离。**正确做法是"定性 + 纪律"双轨**：定性决定"不按景气见顶清仓"，纪律决定"破位照减"——**两者不冲突，不能用定性否定纪律**。

**核心方法：先区分"跌估值端"还是"跌产业端"**

| 维度 | 跌估值端（贴现率上行） | 跌产业端（景气见顶） |
|------|---------------------|-------------------|
| 驱动 | 利率/通胀预期 → 折现率上行 | 需求转弱 → 供需逆转 |
| 传导链 | 油价↑ → 通胀预期↑ → 债券收益率↑ → 加息预期↑ → 杀估值 | 下游订单缩减 → 价格见顶 → 库存堆积 |
| 盘面特征 | **长久期资产领跌**（设备/成长股跌幅 > 晶圆制造股）；产业龙头相对扛跌 | 全链条普跌，**下游/终端先崩**，上游价格同步松动 |
| 产业信号 | 价格仍在涨、订单仍在、无迭代放缓 | 价格见顶或转跌、订单缩减、模型迭代放缓 |
| 郑希框架定性 | **中间变化**——按交易纪律应对，**不改中期方向判断** | **景气见顶**——左侧退出，寻找下一个拼接方向 |
| 应对 | 减仓节奏服从水位线/流动性纪律；盯宏观验证日历 | 逢反弹退出，不等止损位（郑希左侧退出原则） |

**判断口诀**：看"**谁跌得最狠**"——设备/高估值成长领跌、制造龙头扛跌 = 估值端；下游先崩、上游价格松动 = 产业端。

**观测指标与取数**（接口见 `data-access.md` 第二节）：
- 美债 10 年期收益率——全球收益率上行直接压制成长股估值
- 布伦特 / WTI 原油——地缘冲突 → 通胀预期 → 利率预期
- 美联储加息概率（市场定价）
- 费城半导体指数、纳指——海外映射，见 `sector-views.md` 第八节
- 伦敦金——实际利率的镜像，对黄金类持仓有直接影响

**与郑希自身宏观判断的关系**：郑希在 2026 年中报判断"美国利率见顶、美联储进入降息通道"。但他同时强调"**不能有长期判断就忽略中间变化**"——因此当市场定价与其判断背离时（如 2026-09 市场转而定价 9 月加息），正确做法**不是坚持长期判断**，而是把宏观背离列为一级跟踪变量，在验证日历（非农 / CPI / FOMC）落地前保持防守姿态。

**实操定位**：宏观维度的作用**不是预测宏观**，而是给"**这波跌是什么性质**"定性——从而决定是按交易纪律应对，还是按景气见顶退出。

### 郑希的实际跟踪案例

> "去问他的竞争对手上游下游，包括他自身价格的变化，和他客户对他采购的计划的变化，和他客户会不会引入新的竞争者等种种情况。根据他们的动态的变化去匹配，我觉得市场大概对他是什么样的预期。"

郑希甚至远赴海外做实地调研：
- 去美国跟日本同业交流
- 慢慢拼凑出行业全貌
- 从"逐步拟合真相"到"相对成型有信心"

## 三、退出条件判断

### 退出机制总框架（2026-08新增，上海证券报专访披露）

> "在决定投资某一家公司时，我不仅看重其未来发展前景，而且会考虑何时退出。为此他构建了一套基于交易、基本面和估值的退出机制，并将流动性视为控制风险的关键因素。"

郑希的退出决策分三层，与下面三个退出条件一一对应：

| 层面 | 触发条件 | 对应退出条件 |
|------|---------|------------|
| 交易层面 | **量能异常**（放量破位 / 缩量枯竭）+ 交易过度拥挤 | 退出条件3（量价四象限） |
| 基本面层面 | 产业底层逻辑 / 公司或行业竞争格局出问题 | 退出条件1、2 |
| 估值层面 | 估值超出合理区间 | 退出条件1的辅助信号 |

### 退出条件1：景气度见顶

**信号识别**：
- 行业增速放缓 → 上行中段→高位见顶的转折
- 库存开始堆积 → 供过于求的早期信号
- 价格见顶 → 最直接的景气见顶信号

**科技行业特有信号**：
- 模型迭代速度放缓 → 科技景气见顶信号（郑希2024年的实操案例）

> "比如2024年左右看到模型能力迭代速度放缓时，我就选择了先卖出相关标的规避风险。"

**退出方式**：
- **左侧退出**是常态——不等"确认见顶"才退出
- 见顶信号初现即减仓，不是等所有人都确认才动

### 退出条件2：逻辑被破坏

**核心原则**：原始买入逻辑被证伪 → 无条件退出

**典型场景**：
- 买入是因为"行业弱但公司强" → 发现公司竞争力也在下降 → 退出
- 买入是因为"重投入方向对" → 发现投入方向判断错误 → 退出
- 买入是因为"景气上行初期" → 发现景气判断有误 → 退出

### 退出条件3：量能异常（量价四象限）

> **2026-09-06 重构说明**：本节原标题为"流动性恶化"，**只覆盖了"缩量"一种情形**。实战演练（2026-09-04）发现这是重大缺口——当日 512760 成交额较前两日**放大 80%** 破位下跌，按原文标准"流动性正常"，实际却是最危险的信号。**量能的方向比大小更重要**，故重构为四象限。

**核心原则**：流动性风险不只是"枯竭"，**异常放量同样危险，且含义完全相反**。判断时必须先看**量能方向**，再看**价格方向**。

> "流动性，其这就成交量和流动性都是很好的，所以它一定程度上是保护了我撤出的时候的代价。"
> ——郑希原话强调的是"**能退出**"，因此本节第一象限（放量）通常反而更安全；放量下跌之所以危险，不是流动性问题，而是**破位**。

**量比基准**（先算这个，否则"放量/缩量"无意义）：

```
量比5 = 当日成交量 / 前 5 日均量        ← 标准基准
量比2 = 当日成交量 / 前 2 日均量        ← 敏感基准（辅助）

判定：量比5 > 1.5 → 放量；  < 0.7 → 缩量； 之间 → 常态
```

**为什么需要两个基准（2026-09-06 实测发现的陷阱）**：

5 日基准平滑但**滞后**——若前几日刚经历放量，会抬高均值、掩盖当日的急剧变化。实践案例：2026-09-04 的 512760，量比5 = **1.40（常态）**，但量比2 = **1.68（放量）**，实际确为放量破位。**只看 5 日基准会漏掉信号。**

| 情形 | 判读 | 处置 |
|------|------|------|
| 量比5 与 量比2 同向（都放量/都缩量） | 信号明确 | 按四象限正常处置 |
| **量比2 放量但量比5 常态** | **急性放量**——前几日缩量后的突然放大 | ⚠️ **按放量处理**，短基准优先（滞后基准会漏信号） |
| 量比5 放量但量比2 常态 | 放量已在持续，非新增变化 | 按常态处理，观察是否已进入下跌尾声 |

> **实操建议**：**量比2 优先判方向，量比5 判持续性**。两者冲突时取更敏感的那个——漏掉破位信号的代价，远大于误判一次放量。

> 取数：`data-access.md` 第二节第 2 条 K线接口的成交量字段（第 6 位），该文件附量比计算代码。**切勿只看绝对成交额**——不同标的、不同时期的可比性差，必须用相对自身的量比。

**四象限判读与处置**：

| | **价格下跌** | **价格上涨** |
|---|---|---|
| **放量**（量比>1.5） | 🔴 **放量破位**<br>恐慌抛售 / 机构集中出货<br>**处置：触发水位线减仓**（技术止损层），不等景气判断<br>⚠️ 这是最容易被漏掉的信号——流动性指标看着"健康" | ✅ **放量突破**<br>资金进场，趋势确认<br>**处置：持有；若站稳可考虑加**<br>（需与景气方向一致才加） |
| **缩量**（量比<0.7） | ⚠️ **缩量阴跌**<br>流动性枯竭 / 无人接盘<br>**处置：郑希"流动性第一"退出信号**——优先退出，不等景气判断 | ⚠️ **缩量反弹**<br>反弹乏力，买盘不足<br>**处置：不追高，观察；反弹到位按计划减** |

**两类"减仓"的本质区别（不可混淆）**：

| | 缩量阴跌（枯竭） | 放量破位 |
|---|---|---|
| 风险性质 | **退不出来**——想卖时无对手盘 | **卖得掉但价格崩**——对手盘在恐慌抛 |
| 郑希原则 | 流动性第一 → **优先退出** | 交易纪律 → **按水位线减仓** |
| 是否可逆 | 流动性恢复可回补 | 需等企稳信号（缩量止跌） |
| 紧迫度 | 中（可择机） | **高（破位即执行）** |

**实操要点**：

1. **先看量比再看价**——同样跌 3%，放量破位与缩量阴跌的处置完全不同
2. **放量下跌后等"缩量止跌"**——放量破位通常不会一日结束，企稳信号是成交量萎缩且不再创新低
3. **放量上涨也要看方向是否合规**——若与景气方向相悖（如景气下行中的放量反弹），可能是资金炒作而非趋势反转，不追
4. **极端值参考**：成交额降至历史高峰的 20-25% 以下 = 枯竭；单日量比 > 2.5 且下跌 = 恐慌，往往接近短期底部（反而可能是机会，而非再加码卖出）

> **实战案例（2026-09-04，512760）**：收 1.036（-2.81%），成交额 3.79 亿。
> - **量比2 = 1.68（放量）**、**量比5 = 1.40（常态）**——两基准冲突，按"短基准优先"判定为**放量破位**
> - 当日最低 1.028，已下探 1.031 双底生命线下方（收盘 1.036 勉强收回）
> - **演练中正是因为本节原本只覆盖"缩量"，险些漏掉减仓信号**；若只看绝对成交额 3.79 亿（高于此前 2.1 亿），还会误判为"流动性健康、无需动作"

**实操含义**：
- 流动性恶化时，无论景气判断如何，优先减仓
- 这是郑希风控的底线——确保退出能力比判断正确更重要

## 四、风控的哲学层面

### "焦虑过程、平静结果"

> "一方面我觉得就是我的结果比较平淡，我其实是很平淡的，然后对过程我会比较焦虑。"

**核心理解**：
- 过程焦虑 = 密集跟踪、反复验证、动态调整 → 这是日常工作，不是额外负担
- 结果平静 = 接受不确定性，不追求极致排名 → 做好过程就够了

> "实际上我早就准备好被淘汰了。因为我觉得像我这个管理方法被淘汰是必然的，因为它非常消耗精力。所以我只是想在我被淘汰之前，我觉得我能做的好一点。"

**实操含义**：
- 不要追求"完美决策"——密集跟踪+动态调整是正常状态
- 过程做好后，对结果坦然接受——该来的自然会来
- 风控不是要消除风险，而是管理风险——确保犯错时损失可控

## 五、风控实操检查清单

用郑希方法管理持仓时，定期做以下检查：

### 每周检查
- [ ] **量比是多少？**（当日量 / 前5日均量）——>1.5 放量、<0.7 缩量
- [ ] **落在量价四象限哪格？**（放量跌 / 缩量跌 / 放量涨 / 缩量涨）→ 对应处置
- [ ] 持仓标的流动性是否正常（成交额/换手率，是否跌破枯竭阈值）
- [ ] 是否跌破预设水位线（支撑/生命线/止损）
- [ ] 景气度中间信号是否有变化（价格/订单/产能）
- [ ] 是否有新的竞争对手/替代技术出现

### 每月检查
- [ ] 景气度位置是否需要重新判断
- [ ] ROE趋势是否如期改善
- [ ] 客户/竞争/供应链三维度是否有重要变化
- [ ] 是否有更好的景气方向值得切换

### 季度检查
- [ ] 季报数据是否验证了景气判断
- [ ] 买入逻辑是否仍成立
- [ ] 是否需要退出（景气见顶/逻辑破坏/量能异常）

## 数据查什么

> **取数入口**：先读 `data-access.md`——三级取数策略（wb-finance-skill 路由 → 命令层 → 免费 HTTP 接口降级）。下方命令属 L2 命令层，执行前先确认工具可用（`command -v westock-data`）；不可用时按 data-access.md 降级到免费接口。宏观传导数据（油价/金价/美债收益率）见 data-access.md 第二节第 5 条。

- **量能/流动性** → K线接口算**量比**（见 `data-access.md` 第二节量比计算），再套四象限；简单看盘可用 `westock-data quote <code>` 成交额/换手率

- **供应链** → neodata "XX行业上游价格中游库存下游订单" + `westock-data sector`
- **景气位置** → 参考 prosperity-cycle-guide.md 的数据查什么
- **资金流向** → `westock-data asfund <code>` 看资金方向验证
