# 选股框架：低ROE买入与周期拼接

> **何时参考**：用户问"郑希怎么选股 / 低ROE选股 / 这只股郑希会看吗 / ROE从低到高 / 中小盘选股 / 郑希选股标准"。

## 核心目标

回答三件事：**郑希选什么类型的资产、为什么选这种类型、具体筛选条件如何映射到数据指标**。

---

## 一、低ROE选股逻辑——郑希最独特的选股特征

### 为什么买低ROE？

> "我肯定是喜欢ROE低的东西，这点可能跟真正喜欢成长的是不太一样。"

郑希买的是ROE从低到高的**过程**（变化），不是高ROE的**状态**（存量）：

- 低ROE → 景气上行 → ROE提升 → 收益最大化
- 高ROE → 变化空间小 → 弹性有限
- 高ROE的公司是"已经好"的公司，不是"将要变好"的公司

> "我买景气的周期的股票，只买的是一个ROE从低到高的过程。所以它越低它向上高的能力就会大。"

### 低ROE的两种值得买的情况

ROE低有很多原因，但郑希只喜欢两种：

#### 类型A：行业弱导致低ROE，但公司本身有竞争力

> "确实行业很差导致他ROE很低，只是说他长期一个被低估的一个状态，并不代表他只能做到这么低的ROE，是因为现阶段的供求关系决定了它只能在一个比较低的值。"

**验证条件**：
- 行业下行时公司仍比同行好（成本优势/渠道优势/品牌优势/技术优势）
- 公司的ROE低是因为行业周期压低，不是因为公司能力不足
- 在行业复苏时，这类公司的ROE弹性最大

**买入时机**：行业景气度开始反转信号出现时

**数据验证**：
- 同行ROE对比：同行普遍低但目标公司相对较高 → 类型A候选
- 查毛利率/费用率趋势：下行期仍保持优势 → 竞争力证据
- 查行业景气指标：确认行业是否在反转拐点

#### 类型B：前期重投入导致低ROE，投入方向正确

> "我更喜欢的是第二种，就它的ROE低是它在这之前做了大量的预先性研发，而他的这个投入的方向，又是跟我觉得后面要警惕起来的方向是一一致的。所以到时候他的产品卖的时候，就是他之前投的那些钱的回报会放大很多倍回报回来。就是这种带来的ROE提升是非常区别的。"

**验证条件**：
- 公司在正确方向上做了大量前期投入（研发/产能建设）
- 投入方向与未来景气方向一致（关键判断！）
- 投入即将开始产出（客户开始买单/产品放量）

**买入时机**：投入转化信号出现时（订单放量/收入拐点/客户采购计划明确）

**数据验证**：
- 查研发支出占比：高研发+低ROE → 类型B候选
- 查收入拐点：研发转化开始体现 → 买入时机信号
- 查客户/订单：大客户采购计划 → 景气方向确认

### 不值得买的低ROE

以下情况的低ROE不值得买：
- 公司能力不足导致的低ROE（行业好但公司差）
- 投入方向错误导致的低ROE（投入方向与景气方向不一致）
- 缺乏流动性的低ROE（买进去出不来，风控底线）

## 二、中小盘偏好

### 为什么偏好中小盘？

> "小公司一般ROE都是比较低的，碰上一个好的产业周期的时候，因为它基数小，所以它的利润的放大倍数和市值放大倍数对本身的阻力就比大公司要小。"

**核心逻辑**：
- 基数低 → 周期来时乘数更大 → 收益弹性更大
- 低ROE + 景气反转 + 小基数 = 最大收益弹性组合

### A股中小盘的特殊优势

> "A股即便是很小的公司，它还是会有流动性。因为只要有流动性，你就不会出不来……我真实想表达的是，其实在A股中小市值的保护是超越其他市场的，这里本身就有超额收益。"

**核心逻辑**：
- A股中小盘流动性比港股/美股小盘好 → 有流动性保护
- 流动性是郑希风控的底线 → 流动性有保护 = 风控有底气
- 这种超额收益来自市场结构差异，不是来自公司本身

### 中小盘筛选条件

郑希偏好中小盘但没有严格数值界限。基于其公开表述，可归纳为：
- **市值范围**：100亿-500亿（非严格界限，但大概率在此区间）
- **流动性底线**：日均成交额 > 5000万（确保退出能力）
- **不选流动性差的标的**（风控优先原则）

**重要提醒**：中小盘偏好是在**景气方向确定 + 低ROE条件满足**之后的加分项，不是独立选股标准。不能只因为市值小就买，必须先通过景气度和低ROE筛选。

## 三、流动性第一原则

> "我会很关注流动性，或者说我会做一些长期的判断。我真正的组合管理是非常依赖于动态跟踪的。"

**核心逻辑**：
- 买入前先确认能不能卖出去
- 流动性好 → 犯错时能退出 → 风险可控
- 流动性差 → 犯错时可能出不来 → 风险不可控

**实操筛选**：
- 确保目标标的日均成交额足够
- 避免买入流动性恶化的标的（成交量萎缩/换手率骤降）
- 流动性出问题时优先退出

> "如果一家公司缺乏流动性，即使再具备反映行业发展趋势的能力，也可能导致最终的收益大打折扣。"（上海证券报专访，2026-08新增）

## 四、景气关联度与退出机制（2026-08新增）

### 景气关联度——被忽视的硬筛选条件

> "尽管有些公司运营稳健且盈利能力出色，但如果其业绩表现与所处行业的发展变化关联度不高，这类公司也不是我投资的首选。"（上海证券报专访）

**理想标的**：产业因新技术迭代处于上升周期时，企业能站在风口之上，**利润增长与行业上行趋势同步甚至超预期**。

**实操含义**：选股时除低ROE+流动性外，还要验证个股与行业景气的**beta关联度**——公司优秀但与景气无关 → 排除。

### 组合集中度数据

- 前十大重仓股集中度**常年保持在50%以内**（上海证券报专访披露）
- 郑希淡化仓位管理，转而**通过调整行业比例来平衡风险**
- 分散持仓是方法论要求："分散既是对风险的抵御，也是对机会的储备"

### 退出机制

> "在决定投资某一家公司时，我不仅看重其未来发展前景，而且会考虑何时退出。为此他构建了一套基于交易、基本面和估值的退出机制。"（上海证券报专访）

**三层退出触发**：
1. **交易层面**：流动性恶化/交易过于拥挤 → 微调比例或退出
2. **基本面层面**：产业底层逻辑、公司或行业竞争格局出现问题 → 卖出
3. **估值层面**：估值超出合理区间 → 减仓

## 五、郑希选股 vs 通用选股核心差异

| 维度 | 通用成长股投资 | 郑希景气度投资 |
|------|-------------|-------------|
| ROE偏好 | 高ROE（已优秀） | 低ROE（将变好） |
| 低ROE原因 | 视为风险信号 | 视为机会（若原因正确） |
| 市值偏好 | 大盘龙头 | 中小盘弹性 |
| 持有逻辑 | 长期持有优秀公司 | 拼接景气周期 |
| 退出条件 | 公司变差 | 景气度见顶/周期结束 |
| 关注重点 | 公司护城河 | 行业景气拐点 |
| 流动性态度 | 可承受较差流动性 | 流动性第一，必须确保退出 |
| 分散程度 | 高集中度 | 较低集中度（前十大常年≤50%） |
| 景气关联度 | 不强制 | 硬条件——业绩须与行业上行同步（2026-08新增） |

## 六、选股数据映射与筛选命令

### 低ROE选股筛选（westock-tool filter）

筛选低ROE但有改善迹象的标的：

```
# 筛选A股低ROE（0-10%）中小市值标的
westock-tool filter "intersect([ROETTM > 0, ROETTM < 10, TotalMV > 100, TotalMV < 500])" --orderby ROETTM --asc

# 筛选特定行业低ROE标的（如光通信）
westock-tool filter "intersect([ROETTM > 0, ROETTM < 15])" --sector BK1215 --orderby ROETTM --asc

# 筛选低ROE港股科技标的
westock-tool filter "intersect([RoeWeighted > 0, RoeWeighted < 10])" --market hk --orderby RoeWeighted --asc
```

### ROE趋势与同行对比（westock-data / neodata）

判断低ROE原因（类型A vs 类型B）：

```
# 查个股多期财务数据（ROE趋势）
westock-data finance <code> --num 8

# 查同行对比
neodata "XX行业近5年ROE排名对比"

# 查研发投入（判断类型B）
westock-data finance <code> --num 8  # 看研发费用率趋势
neodata "XX公司近5年研发支出占比营收"
```

### 市值与流动性验证

```
# 查市值和成交额
westock-data quote <code>  # 看 TotalMV 和日均成交额

# 查板块成分（用于同行对比）
westock-data sector constituent <板块代码>
```

## 七、选股流程实操

用郑希方法选股的完整流程：

1. **确定景气方向** → 参考 `prosperity-cycle-guide.md`
   - 哪个行业景气正在反转/上行？
   - 通胀类型是什么（科技通胀 vs 传统通胀）？

2. **在该行业内筛选低ROE标的**
   - 用 westock-tool filter 筛选低ROE
   - 确认流动性达标

3. **判断低ROE原因**
   - 类型A（行业弱但公司强）→ 验证同行对比
   - 类型B（重投入方向对）→ 验证研发投入与转化信号

4. **确认景气拐点信号**
   - 行业反转信号是否出现（价格/订单/产能利用率）
   - 类型B：投入转化信号是否出现（收入拐点/客户采购）

5. **综合判断** → 参考 `decision-flowchart.md`
   - 景气上行 + 低ROE + 有竞争力 = "郑希最想买"
   - 景气不明 + 低ROE = "观察，不急于入场"
   - 低ROE原因不对（能力不足/方向错误） = "不值得买"

## 数据查什么

> **取数入口**：先读 `data-access.md`——三级取数策略（wb-finance-skill 路由 → 命令层 → 免费 HTTP 接口降级）。下方命令属 L2 命令层，执行前先确认工具可用（`command -v westock-data`/`westock-tool`）；不可用时按 data-access.md 降级到免费接口。
