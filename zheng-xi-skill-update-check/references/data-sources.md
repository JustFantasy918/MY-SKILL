## 五、抓取注意事项

1. 官网报告页偶尔需重试（加 `?from=` 参数）。
2. 东方财富/腾讯新闻（gu.qq.com）的 JS 渲染页面 WebFetch 可能失败，改用 WebSearch 找同内容其他来源。
3. 半年报（中期报告）含全部持仓明细（11-20 大重仓股），季报只有前十大——半年报价值更高。
4. 简历变化也是信号：职务、管理规模、兼任信息的变化需记录。
